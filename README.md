# BLONDED

Recreación visual de la tienda blonded.co: navbar blanca, reloj, y la ficha de BLONDE 2LP. CART no abre un carrito. Alterna dos versiones del sitio.

## Cómo verlo

```bash
npm install
npm run dev
```

Abre http://127.0.0.1:43123

## Dos versiones

CART (o la tecla `Y`, fuera de un campo de texto) cambia entre:

1. El catálogo en blanco, con la foto del vinilo.
2. Un modo oscuro de carbón y negro, con un acento ácido. La foto pasa a un negativo en alto contraste, con grano. Un Testarossa rojo en pixel art cruza la pantalla.

Vuelve a pulsar CART para regresar. La lista de correo y el acceso se quedan en la página: el envío no sale de este navegador.
